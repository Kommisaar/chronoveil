二、多角色目标态（模板 / 实例分离 · 已拍板）

核心变化：角色卡降级为纯模板库（与运行时解耦）；新建 character_instances 承接全部运行时角色身份——设定快照进实例，改卡不影响已开会话。sessions.character_id 删除，扮演位由 is_user 表达；messages.character_id 死列激活升级为 instance_id；状态唯一约束简化为 (instance_id, key)。

三、生成链路上的角色读取（现状 vs 目标态）

现状：generation → get_character(会话.character_id) → 单 Character 进 prompt → 单人装配。
目标态：generation → 按 session_id 取 roster（实例数组，is_user 标「你」）→ Q1 逐拍：每个 LLM 位实例独立一次生成（用户位由你输入）→ 各自 persona 快照 + 各自状态/关系分视角装配 → 轨迹面板天然显示 N 次调用的归属。
