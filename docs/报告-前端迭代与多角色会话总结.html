目标：一致性 / 易用性 / 美观度 / 动画一致性，用户授权破坏性改造。三轮 iter-scout 审计驱动（18+6+第三轮在飞），16 任务（15 已合并 + 1 在飞），全部后台并行 + worktree 池化执行。

一致性

确认族统一

ConfirmDialog 收编五处对话框；补齐角色页 Esc 不可取消；破坏性键红描边弱化 + 取消键主键化；busy 防双击。

幽灵图标钮收敛

9 处手写「原生 button 抹平」迁入 useGhostIconButtonStyles（28/36 两档），键盘焦点环全量补齐。

Tooltip 全量接管

原生 title 清零（label/inaccessible 分型），悬停提示获得键盘可达与统一延迟观感。

圆角三档规范

页面级 16px（SURFACE_RADIUS_PAGE_CARD 常量闭环）/ 分组卡 Large(6px) / 行内 Medium(4px)——实测纠错 Fluent token 档位。

易用性（含两个正确性修复）

  • IME 守卫：中文输入法按 Enter 确认候选词不再误发半截消息（红测试先行复现）。
  • 切会话竞态守卫：快速切换不再出现旧会话消息串台（resolve 顺序反转复现）。
  • 智能吸底：流式输出时上滚阅读不再被拽回（距底 80px 阈值）。
  • 空态直达：零会话即可点「新建会话」，不再依赖可收起的侧栏「+」；文案指引同步修正。
  • 删模型确认：唯一/全局默认模型删除先确认（次级文字对比度连带修复 0.66→0.8）。
  • 禁用钮可达：发送/停止/重新生成禁用态改 disabledFocusable——「为什么发不出去」悬停可见。

美观度

  • 三态同构：StateBlock 统一承载全部视图——加载不再整页空白、错误带重试且 role="alert"、空态两级形制（页面级/段内）成文。
  • 对比度守卫：UI 层 55 用点 WCAG AA 实测（复用引擎公式）；选人卡与海报文字压暗层（0.62 下限，最坏白 accent 数学推导 6.19:1 入守卫）。

动画一致性

  • motion token 单源：曲线 3 档 + 时长 7 档，CSS 走 --cv-* 互指，全仓扫描守卫锁死字面量位置；400/480ms 漂移实证归并。
  • stagger 统一：清单浮现 24ms + 360ms 封顶（原侧栏 16/240 vs 卡墙 60/无封顶差 3.75 倍）。
  • reduce 门控：prefers-reduced-motion 补齐 6 处（卡片浮起、侧栏收展、色块环、chevron、思考淡入）。
  • 思考两态过渡：终态 Accordion 200ms 淡入（重挂载机制下按拍板方案落地；真交叉淡化需动 settle 竞态，留独立议题）。
